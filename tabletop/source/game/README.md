# Единый эталон «Путей Раскола»

Редактируйте игру только здесь:

- `game.json` — каталог карт (название, сила, значок, текст, изображение), состав колоды каждого игрока, базы, барьеры, поле и рубашки;
- `rules.md` — полный текст правил;
- `assets/` — исходные иллюстрации, поле, рубашки и текстуры карточек.

Одна запись в `cards` описывает тип карты. `player_deck` задаёт порядок типов в атласах и число копий каждого типа в обеих колодах. Чтобы добавить карту, добавьте её в `cards`, положите изображение в `assets/` и добавьте запись `{ "card": "идентификатор карты", "count": 1 }` в `player_deck`. Для второй копии измените `count` на `2`.

Идентификаторы карт стабильны: переименование или изменение способности не требуют нового `id`. Сила записывается числом, значок — строкой Unicode, изображение — относительным путём `assets/имя.jpg`. Поле `label` необязательно и используется при экспорте PlayingCards.io.

Сборка: `python3 scripts/build_game.py` из корня проекта. Результаты находятся в `output/build/`. Файлы в `source/templates/` отвечают только за оформление и расположение объектов платформ; тексты карт оттуда не берутся.

Исходники в `source/pcio/` и `source/extra_cards.json` сохранены как архив миграции. Сборка их больше не читает. Идеи и запланированные изменения правил остаются в корневом `TODO.md` до отдельной реализации.
